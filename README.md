# Calculadora de Stats — Dandy's World

Calculadora web en español para estimar estadísticas de Toons y aplicar modificadores. Está hecha con HTML, CSS y JavaScript, sin dependencias externas.

## Funciones

- Calcula **Extraction Speed**, **Movement Speed** (Walk y Run), **Skill Check Size**, **Stamina** y **Stealth**.
- Permite elegir un objetivo de 1 a 5 estrellas y comparar el resultado calculado con los niveles de estrellas.
- Aplica modificadores multiplicadores, porcentuales y de valor plano; en Movement Speed se puede elegir si afectan a Walk, Run, ambos o ninguno.
- La pestaña **Valores aplicados** muestra y permite quitar modificadores.
- La pestaña **Estrellas elegidas** resume el nivel seleccionado para cada estadística, incluyendo Walk y Run, y se adapta a pantallas pequeñas.

## Uso

1. En **Calculadora**, elige una estadística y el nivel de estrellas que quieres consultar.
2. Introduce el valor base del Toon. Para Movement Speed, puedes editar las bases de Walk y Run.
3. Ajusta los campos del modificador y pulsa **Añadir modificador**. Puedes quitar uno en **Valores aplicados** o eliminarlos todos.
4. Consulta el resultado y las pestañas de resumen. Las selecciones de estrellas se conservan al cambiar de estadística.
